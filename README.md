# 🧠 Quiz Web Project

A simple and interactive web-based quiz application designed to test users' knowledge of computer science and programming through multiple-choice questions.

## 📌 About the Project

**Quiz Web Project** is a responsive quiz application built using **HTML, CSS, and JavaScript**. The questions are stored in a JSON file, allowing the application to dynamically load and display quiz questions.

The application provides an interactive quiz experience with a timer, score tracking, and navigation controls.

## ✨ Features

* 📝 Multiple-choice questions
* ⏱️ Countdown timer
* 📊 Real-time score tracking
* ⬅️ Previous question navigation
* ➡️ Next question navigation
* 📚 200 questions stored in JSON format
* 📱 Responsive design
* 🎯 Questions focused on Computer Science and Programming
* 🔄 Dynamic question handling using JavaScript

## 🛠️ Technologies Used

* **HTML5** — Structure and layout
* **CSS3** — Styling and responsive design
* **JavaScript** — Quiz logic, timer, navigation, and score calculation
* **JSON** — Storing and managing quiz questions

## 📂 Project Structure

```text
Quiz-web-project/

├── 200 questions.json   # Quiz questions and answers

├── CSS.css              # Styling and responsive design
├── JAVA.js              # Quiz logic and functionality

```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Rawda11-Mohamed/Quiz-web-project.git
```

2. Open the project folder.

3. Open `HTML.html` in your web browser.

4. Start answering the quiz questions.

No additional installation or dependencies are required.

## 🎮 How It Works

1. The application loads quiz questions from the JSON file.
2. A question with multiple answer choices is displayed.
3. The user selects an answer.
4. The score is updated based on the selected answer.
5. The timer keeps track of the remaining time.
6. The user can navigate between questions using the Next and Previous buttons.
7. The final score represents the user's performance in the quiz.
